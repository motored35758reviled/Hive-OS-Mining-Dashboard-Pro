## Frequently Asked Questions

### Will this work with my existing Hive OS account?
Yes. Simply log in with your current Hive OS credentials during the first launch. All of your rigs, pool configurations, wallet addresses, and worker groupings will be imported and synchronized automatically.

### Does the application support both AMD and NVIDIA GPUs?
Absolutely. Full support for all modern AMD Radeon and NVIDIA GeForce GPU series is included. You can manage mixed-fleet environments with both architectures in the same dashboard without any compatibility issues.

### What happens if a rig goes offline?
The alert and notification engine detects offline rigs within seconds and can deliver a desktop pop-up, an email, or both. You can customize detection intervals and notification preferences in the Settings panel.

### Can I install this on more than one computer?
Yes. There is no limit on the number of installations per account. Your data syncs across every instance, so you can monitor your farm from your office PC, a laptop, or any other Windows machine.

### Is a portable version available?
Not at this time. A portable, no-install version is planned for a future release. Watch this repository for updates and announcements.
